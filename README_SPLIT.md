# LinkedIn Job Application Bot - Split Functionality

This project has been split into two main components for better organization and flexibility:

1. **Job Fetcher** (`job_fetcher.py`) - Fetches relevant jobs based on user description
2. **Auto Applier** (`auto_applier.py`) - Automatically applies to jobs from the fetched list

## Overview

The original monolithic LinkedIn job application bot has been restructured into two separate modules:

- **Job Fetcher**: Searches LinkedIn for jobs based on your criteria and saves them to `applicable.csv`
- **Auto Applier**: Reads jobs from `applicable.csv` and automatically applies to them using Easy Apply

## Files Structure

```
├── job_fetcher.py          # Job fetching functionality
├── auto_applier.py         # Auto-applying functionality  
├── main.py                 # Main orchestrator script
├── applicable.csv          # Generated file with fetched jobs
├── config/                 # Configuration files
│   ├── personals.py       # Personal information
│   ├── questions.py       # Question handling
│   ├── search.py          # Search parameters
│   ├── secrets.py         # Credentials and AI settings
│   └── settings.py        # General settings
└── modules/               # Supporting modules
    ├── open_chrome.py     # Browser setup
    ├── helpers.py         # Helper functions
    ├── clickers_and_finders.py  # UI interaction
    ├── validator.py       # Configuration validation
    └── ai/               # AI integration modules
```

## Usage

### Option 1: Run Both Parts (Recommended)

```bash
python main.py
```

This will:
1. Fetch relevant jobs based on your configuration
2. Save them to `applicable.csv`
3. Automatically apply to jobs with Easy Apply

### Option 2: Run Only Job Fetching

```bash
python main.py --mode fetch
```

This will only fetch jobs and save them to `applicable.csv`. You can review the jobs before applying.

### Option 3: Run Only Auto-Applying

```bash
python main.py --mode apply
```

This will only apply to jobs from the existing `applicable.csv` file.

### Option 4: Run Individual Modules

```bash
# Fetch jobs only
python job_fetcher.py

# Apply to jobs only
python auto_applier.py
```

## Configuration

All configuration is handled through the `config/` directory:

### `config/personals.py`
- Personal information (name, contact details, etc.)
- Salary expectations
- Work preferences

### `config/search.py`
- Search terms
- Location preferences
- Job filters (experience level, job type, etc.)

### `config/secrets.py`
- LinkedIn credentials
- AI provider settings (if using AI for answers)

### `config/settings.py`
- General bot settings
- Timing parameters
- Behavior controls

## Workflow

### Step 1: Job Fetching
1. The bot logs into LinkedIn
2. Searches for jobs based on your criteria in `config/search.py`
3. Filters jobs based on blacklist words and requirements
4. Checks if Easy Apply is available
5. Saves relevant jobs to `applicable.csv`

### Step 2: Auto-Applying
1. Reads jobs from `applicable.csv`
2. Filters for jobs with Easy Apply
3. Navigates to each job page
4. Fills out application forms automatically
5. Submits applications
6. Records results in the main application CSV

## CSV File Structure

### `applicable.csv` (Generated by Job Fetcher)
```csv
Job ID,Title,Company,Work Location,Work Style,Job Link,Description,Experience Required,Date Posted,Easy Apply Available
123456,Software Engineer,Google,Remote,Remote,https://linkedin.com/jobs/view/123456,Job description...,3,2 days ago,true
```

### Main Application CSV (Updated by Auto Applier)
```csv
Job ID,Title,Company,Work Location,Work Style,About Job,Experience required,Skills required,HR Name,HR Link,Resume,Re-posted,Date Posted,Date Applied,Job Link,External Job link,Questions Found,Connect Request
```

## Benefits of Split Architecture

1. **Flexibility**: You can fetch jobs once and apply multiple times
2. **Review**: You can review the fetched jobs before applying
3. **Debugging**: Easier to identify issues in either fetching or applying
4. **Resume**: Can resume applying if interrupted
5. **Customization**: Can manually edit `applicable.csv` before applying

## Advanced Usage

### Custom CSV File
```bash
python main.py --csv-file my_jobs.csv
```

### Limit Applications
```bash
python main.py --max-applications 5
```

### Limit Job Fetching
```bash
python main.py --max-jobs 25
```

## Error Handling

- If job fetching fails, the process stops
- If auto-applying fails, it continues with the next job
- Failed applications are logged
- The bot handles LinkedIn's daily application limits

## AI Integration

If you have AI configured in `config/secrets.py`, the bot can:
- Answer complex questions using AI
- Generate cover letters
- Provide intelligent responses to application questions

## Troubleshooting

1. **No jobs found**: Check your search criteria in `config/search.py`
2. **Login issues**: Verify credentials in `config/secrets.py`
3. **Application failures**: Check if Easy Apply is still available
4. **AI errors**: Verify AI provider settings in `config/secrets.py`

## Safety Features

- Pauses before submitting applications (configurable)
- Handles daily application limits
- Skips already applied jobs
- Respects blacklist words
- Validates job requirements before applying

## Migration from Original Bot

If you're migrating from the original monolithic bot:

1. Your existing configuration files should work as-is
2. The new structure provides the same functionality with better organization
3. You can still use all the same features (AI, custom questions, etc.)
4. The application CSV format remains the same

python main.py --mode fetch
