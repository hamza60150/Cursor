# LinkedIn Job Application Bot - Setup Guide

## Overview

This bot has been split into two main components for better organization and flexibility:

1. **Job Fetcher** - Fetches relevant jobs based on user description and saves them to `applicablejobs.csv`
2. **Auto Applier** - Automatically applies to jobs from the fetched list

## Quick Start

### 1. Install Dependencies

```bash
pip install -r requirements.txt
```

### 2. Configure Your Settings

#### Update `config/secrets.py`:
```python
# LinkedIn Credentials
username = "your_actual_linkedin_email@example.com"
password = "your_actual_linkedin_password"

# AI Settings (optional)
use_AI = True
ai_provider = "openai"  # Options: "openai", "deepseek", "gemini"
openai_api_key = "your_openai_api_key_here"
```

#### Update `config/personals.py`:
```python
# Personal Information
first_name = "Your"
last_name = "Name"
phone_number = "+1234567890"
email = "your.email@example.com"
```

#### Update `config/search.py`:
```python
# Search Terms
search_terms = [
    "Software Engineer",
    "Python Developer",
    "Full Stack Developer"
]

# Search Location
search_location = "San Francisco, CA"
```

### 3. Run the Bot

#### Option A: Run Both Parts (Recommended)
```bash
python3 main.py
```

#### Option B: Run Only Job Fetching
```bash
python3 main.py --mode fetch
```

#### Option C: Run Only Auto-Applying
```bash
python3 main.py --mode apply
```

#### Option D: Run Individual Modules
```bash
# Fetch jobs only
python3 job_fetcher.py

# Apply to jobs only
python3 auto_applier.py
```

## Complete Workflow

### Step 1: Job Fetching
The job fetcher follows this exact workflow:

1. **Fetches credentials** from `config/secrets.py`
2. **Signs in** to LinkedIn using the credentials
3. **Checks sign in** status to ensure successful login
4. **Navigates to Jobs page**
5. **Applies filters** based on your configuration:
   - Search terms
   - Location
   - Experience level
   - Job type
   - **Turns on Easy Apply filter**
6. **Extracts relevant jobs** from search results
7. **Saves jobs** to `applicablejobs.csv`

### Step 2: Auto-Applying
The auto-applier follows this workflow:

1. **Loads jobs** from `applicablejobs.csv`
2. **Filters for Easy Apply jobs**
3. **Navigates to each job page**
4. **Fills out application forms** automatically
5. **Submits applications**
6. **Records results** in the main application CSV

## Troubleshooting

### Common Issues

1. **"No module named 'undetected_chromedriver'"**
   ```bash
   pip install -r requirements.txt
   ```

2. **Login fails**
   - Check credentials in `config/secrets.py`
   - Ensure LinkedIn account is not locked
   - Try manual login first

3. **No jobs found**
   - Check search terms in `config/search.py`
   - Verify location settings
   - Check if filters are too restrictive

4. **Application failures**
   - Check if Easy Apply is still available
   - Review job requirements
   - Check for new question types

### Test Your Setup

Run the test script to verify everything is working:
```bash
python3 test_workflow.py
```

## Benefits of Split Architecture

1. **Flexibility**: Fetch jobs once, apply multiple times
2. **Review**: Can review fetched jobs before applying
3. **Debugging**: Easier to identify issues in either component
4. **Resume**: Can resume applying if interrupted
5. **Customization**: Can manually edit CSV before applying

## Migration from Original Bot

If you're migrating from the original monolithic bot:

1. Your existing configuration files should work as-is
2. The new structure provides the same functionality with better organization
3. You can still use all the same features (AI, custom questions, etc.)
4. The application CSV format remains the same

This split architecture makes the bot more maintainable, debuggable, and user-friendly while preserving all the original functionality.
